# Personal Portfolio

A modern personal portfolio website built with React to showcase my introduction, experience, projects, and contact information in a polished single-page experience.

## Overview

This project is a responsive portfolio site designed to present:

- A short introduction and personal branding section
- A professional experience timeline
- Featured projects and work highlights
- A contact section for reaching out

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- Framer Motion
- React Spring
- EmailJS

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your machine.

### Installation

`
npm install
`

### Run locally

`
npm start
`

Then open http://localhost:3000 to view the site in your browser.


## Deployment

This site is configured for GitHub Pages deployment using the gh-pages package.
